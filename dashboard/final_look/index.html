0Style system: do this once before touching any page

Colours come from GoDesi's own brand: the logo is orange #FF8700 with black lettering, and godesi.in uses teal #108474 as its second colour. Everything else is a neutral built around those three.

Channel colours: same colour = same channel on every page

Steps (Power BI Desktop)

  1. Load the theme: View → Themes → ▾ (bottom arrow) → Browse for themes → pick D:\go_desi\dashboard\godesi_theme.json → Open. Cream page background, white rounded cards and black table headers turn on everywhere.
  2. Canvas size: click an empty spot on the page → Format pane → Canvas settings → Type Custom, width 1920, height 1080. The X / Y / W / H numbers below assume this.
  3. Exact position of a visual: select it → Format pane → General → Properties → Size (Height, Width) and Position (Horizontal = X, Vertical = Y).
  4. Header band (build once on page 1, then copy to every page):
    1. Insert → Shapes → Rectangle. Position 0, 0, size 1920 × 84. Fill #111111, border off.
    2. Insert → Shapes → Rounded rectangle. Position 24, 18, size 144 × 48. Fill #FF8700, border off, Text on: GO DESi, Segoe UI Bold 18, colour #111111, centred.
    3. Insert → Buttons → Navigator → Page navigator. Position 198, 18, size 1080 × 48. Format → Style → State Default: fill off, text #D9D0C5, 16. State Selected: fill #FF8700, text #111111, bold. State On hover: fill #3D3935. Shape rounded, radius 24.
    4. Select the three (Ctrl+click) → Ctrl+C → go to each other page → Ctrl+V. They land in the same place.
  5. Titles: keep your rectangle-shape titles. Move them to 36, 102, size 1230 × 51, Segoe UI Bold 30, #111111. Subtitle shape at 36, 150, 1230 × 33, Segoe UI 16, #6B6257.
  6. Visual titles: short, sentence case (e.g. "Net revenue by month"), no field names like "Sum of NET_REVENUE_INR". Rename in the field well: double-click the field → type a new name.
  7. Series colours: the theme makes the first series orange. For charts with a channel legend, set each series by hand once: Format → Columns (or Lines) → Colors → pick the channel, enter the hex from the table above.
  8. Tidy: turn off the visual header icons you don't need (Format → General → Header icons). Turn off gridlines on bar charts and keep them on column/line charts only.
  9. Before saving: clear both slicers on every page (eraser icon), then File → Save.
All positions, sizes and font sizes are for a 1920 × 1080 canvas. Default font sizes come from the theme (visual titles 18, labels 14). show layout, colour and formatting. Bar lengths, line shapes and most numbers are illustrative: your report fills in the real values. The page titles are your final titles, already checked against Snowflake.
